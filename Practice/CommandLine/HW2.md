## Задание

Напишите простую программу на любом ЯП, которая бы выводила приветствие по заданному имени в вывод терминала.
Сделайте так, чтобы программой можно было пользоваться глобально по её имени.

```bash
# Hello bob smith!
hello bob --lname smith
```
